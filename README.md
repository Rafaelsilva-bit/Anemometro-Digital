# Manômetro Digital

Projeto de desenvolvimento de um manômetro digital para medição de pressão utilizando sensores eletrônicos e sistemas embarcados.

## Objetivos
- Medir pressão em tempo real
- Exibir dados em display OLED
- Realizar calibração do sensor
- Garantir precisão nas medições

## Componentes
- Sensor de pressão
- Display OLED
- Microcontrolador
- Fonte de alimentação

## Funcionalidades
- Leitura contínua da pressão
- Exibição dos valores em tempo real
- Calibração do sistema
- Conversão de unidades
